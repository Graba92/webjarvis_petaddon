# 🐾 Release: Desktop Pet & Tamagotchi AI Companion v3.0 (Codex V2 Fluid Animation Edition)

> **Bring a playful, ultra-fluid, health-guarding Tamagotchi companion to your Linux desktop!** A 100% standalone, anti-aliased PyQt6 desktop buddy featuring OpenPets Codex V2 spritesheets, dynamic SpriteAtlas detection, procedural micro-animations (blush cheeks, eyelid blinking, secondary inertia tilt, toss aerodynamics), 6 bundled companions (including Tux, Clippy, Elara Fox, Yuyu Chibi), OpenPets catalog downloader (300+ pets), universal LLM API-key configuration (Gemini, OpenAI, Groq, OpenRouter, Ollama), 4 distinct character voices, Tamagotchi vitals (hunger, thirst, breaks), petting engine, minigames (fetch, dice, fortune cookie), CPU monitor, Pomodoro timer, RPG progression, and nagging mode!
