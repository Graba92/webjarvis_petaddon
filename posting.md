# 🐾 Release: Desktop Pet & Tamagotchi AI Companion v2.6 (OpenPets Mini Core)

> **Bring a playful, health-guarding Tamagotchi companion to your Linux desktop!** A 100% standalone, anti-aliased PyQt6 desktop buddy featuring OpenPets V2 spritesheets, universal LLM API-key configuration (Gemini, OpenAI, Groq, OpenRouter, Ollama), 4 distinct character voices, Tamagotchi vitals (hunger, thirst, breaks), petting engine, minigames (fetch, dice, fortune cookie), multi-skin switcher, CPU monitor, Pomodoro timer, RPG progression, and a relentless nagging mode!
