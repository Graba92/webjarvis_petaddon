# WebJarvis Desktop Pet - Windows & Universal Community Posting

```text
🐾 WebJarvis Desktop Pet v1.1.0 — OpenPets Native Desktop Companion

Bringe deinen KI-Assistenten zum Leben! Das WebJarvis Desktop Pet bringt einen animierten Begleiter direkt auf deinen Desktop.

Highlights:
- Echter transparenter Desktop-Begleiter (PyQt6 Overlay ohne Fensterrahmen)
- Vollständige OpenPets V2 Spritesheet Unterstützung (192x208 Framegröße)
- 16-Sektor Desktop Cursor-Blickverfolgung (Gaze Tracking)
- Autonomes Wandern (Roaming) am unteren Bildschirmrand
- Live-Reaktionen auf Jarvis WebSocket-Status (Thinking, Speaking, Error, Listening)
- Rechtsklick auf das Pet: Stimmenauswahl (👨 Männlich / 👩 Weiblich), Größe & Einstellungen
- 1-Klick Aktivierungs-Button im WebJarvis Bottom Dock & Kontrollzentrum

Setup:
1. ./install.sh im Addon-Verzeichnis ausführen
2. WebJarvis öffnen & das Pfoten-Icon im Dock anklicken oder direkt ./run.sh starten!
```
