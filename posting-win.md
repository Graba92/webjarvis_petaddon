# WebJarvis Pet Addon - Windows & Universal Community Posting

```text
🐾 WebJarvis Pet Addon v1.0.0 — OpenPets Companion Integration

Bringe deinen KI-Assistenten zum Leben! Das WebJarvis Pet Addon integriert eine leichtgewichtige OpenPets V2 Animation-Engine direkt in die WebJarvis Benutzeroberfläche.

Highlights:
- Vollständige OpenPets V2 Spritesheet Unterstützung (192x208 Framegröße)
- 16-Sektor Cursor-Blickverfolgung (Gaze Tracking)
- Autonomes Wandern (Roaming) über den Viewport
- Live-Reaktionen auf Jarvis WebSocket-Status (Thinking, Speaking, Error, Listening)
- Sprechblasen, Streichel-Interaktion & WebAudio Soundeffekte
- 1-Klick Aktivierungs-Button im Jarvis Bottom Dock

Setup:
1. ./install.sh im Addon-Verzeichnis ausführen
2. WebJarvis öffnen & das Pfoten-Icon im Dock anklicken!
```
